# Artificial accounting demonstration

```sh
.venv/bin/python examples/synthetic_demo.py
```

The included fixture contains 600 invented observations and a flat 4% illustrative borrowing rate. The demonstration uses USD10,000 illustrative capital and its own allocation/cost assumptions. It checks accounting mechanically; it does not reproduce the investment study's performance or replace the original data. Its expected summary is retained in `synthetic_demo_expected.json`.

For the actual research use[the original-data reconstruction](../REPRODUCE.md).
