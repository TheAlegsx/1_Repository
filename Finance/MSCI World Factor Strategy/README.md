# MSCI World Factor Strategy

Public companion to the 10 November 2026 Corporate Finance portfolio backtest. The report and calculation code come from the verified assessment package. Page 7 documents the Quality allocation test and the ten-year fund-assets scenario discussed in the video.

- [Portfolio backtest report](MSCI_World_Factor_Strategy_Backtest.pdf)
- [Code and reproduction instructions](REPRODUCE.md)
- [Data sources](Evidence/Data_Sources.md)
- [Results and provenance](Evidence/results.json)
- [Paired specification results](Evidence/paired_cases.csv)
- [Public file checksums](CHECKSUMS.sha256)

The main comparison uses the common calendar of four iShares ETF NAV series. The separate product comparisons use Amundi issuer NAVs and Dimensional NAVs from Morningstar via Finanzfluss. A full rerun requires authorized copies of the input snapshots and source manifests. The [MIT licence](Code/LICENSE) covers the code.
